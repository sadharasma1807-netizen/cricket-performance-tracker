# 🏏 Cricket Performance Tracker Pro — V2

## Included features
- Player management
- Match performance management
- Automatic Strike Rate and Economy
- Dashboard statistics
- Leaderboard
- Player-wise summary/profile
- Edit player
- Edit performance
- Search players
- Date/opponent/player filters
- Sort performance
- Export players to CSV
- Export performance records to CSV
- Performance bars
- Dark mode
- LocalStorage persistence
- Responsive design

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Right-click → **Open with Live Server**.
5. Chrome opens the dashboard.

Or simply double-click `index.html`.

No Python, Node.js, database, or installation is required.

## Note about old version data
V2 uses a separate LocalStorage key (`cricket_tracker_v2`) so your original V1 data is not overwritten.
